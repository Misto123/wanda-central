Browser Automation Setup

Control Puppeteer, AdsPower & BAS browser instances via API

Supported Providers

Puppeteer Headless Chrome automation
AdsPower Anti-detect browser profiles
BAS Browser Automation Studio
Job Queue Schedule & monitor sessions

API Endpoint

Remote Browser API: http://65.21.199.228:3000

Create browser sessions, execute actions, and retrieve results programmatically.

Start Browser Session

POST http://65.21.199.228:3000/api/browser/start

{
  "provider": "puppeteer",
  "headless": false,
  "viewport": { "width": 1920, "height": 1080 }
}

// Response
{
  "success": true,
  "browser_id": "abc123",
  "ws_url": "ws://..."
}

Execute Actions

POST http://65.21.199.228:3000/api/browser/:id/action

{
  "action": "navigate",
  "url": "https://example.com"
}

{
  "action": "click",
  "selector": "button.submit"
}

{
  "action": "screenshot",
  "path": "/tmp/screenshot.png"
}

Stop Browser

POST http://65.21.199.228:3000/api/browser/:id/stop

// Browser session closed

Track in Wanda Central

All browser sessions are logged in the Jobs tab:

  • Session start/stop times
  • Actions executed
  • Success/failure status
  • Screenshots captured
