Google Search Console Setup

Import search data, track rankings & find keyword opportunities

What You Get

Search Analytics Clicks, impressions, CTR, position
Keyword Tracking Monitor rankings for target keywords
Opportunities Auto-detect position 4-10 keywords
MCP Queries Ask AI agents about your data

Setup Steps

Click Import Wizard

In Wanda Central dashboard, click "Import GSC/GA Data" button

Enter Project Details

Provide project name and domain (e.g., example.com)

Select GSC

Check "Google Search Console" in the data sources step

Authenticate

Sign in with Google and grant Search Console permissions

Daily Sync

Data imports automatically at 2 AM daily

API Query Examples

Query your GSC data programmatically:

// Get top keywords
GET /api/gsc/:project_id/top-keywords?limit=50

// Get keyword opportunities
GET /api/recommendations/:project_id

// Query all search data
GET /api/keywords/:project_id?startDate=2026-08-01&endDate=2026-09-29

MCP Integration

Let AI agents query your GSC data:

{
  "mcpServers": {
    "wanda-gsc": {
      "command": "node",
      "args": ["mcp-servers/gsc/index.js"],
      "env": {
        "SUPABASE_URL": "your-supabase-url",
        "SUPABASE_KEY": "your-key"
      }
    }
  }
}

Ask Claude: "Show me keywords ranking 4-10" or "What are my top performing pages?"
