📝 Content Creator API

Generate SEO-optimized articles for marketplacestudio.nl

📡 API Endpoint

POST https://wanda-central.vercel.app/api/content/generate
⚠️ IMPORTANT - Request Body Structure:
Use keywords.main_keyword NOT main_keyword at root level!

⚡ Quick Start (CORRECT FORMAT)

Generate an article with correct body structure:

fetch('https://wanda-central.vercel.app/api/content/generate', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    keywords: {
      main_keyword: 'marketplace solutions',
      secondary_keywords: ['online marketplace', 'e-commerce platform']
    },
    website_domain: 'marketplacestudio.nl',
    enable_no_ai_slop: true,
    enable_seo_optimization: true,
    article_length_words: 800  // MAX: 1500 words
  })
})
.then(r => r.json())
.then(article => console.log(article));

📝 Complete Example (ALL FIELDS)

fetch('https://wanda-central.vercel.app/api/content/generate', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    keywords: {
      main_keyword: 'marketplace platform',
      secondary_keywords: [
        'online marketplace',
        'e-commerce platform',
        'multi-vendor marketplace'
      ]
    },
    website_domain: 'marketplacestudio.nl',
    enable_first_hand_experience: true,
    first_hand_experience: 'We power 150+ marketplaces with 99.9% uptime',
    enable_no_ai_slop: true,
    enable_seo_optimization: true,
    article_length_words: 1200  // MAX: 1500 words
  })
})
.then(r => r.json())
.then(data => {
  if (data.success) {
    console.log('Article generated!', data.content);
  } else {
    console.error('Error:', data.error);
  }
});

📋 Request Body Schema

FieldTypeRequiredDescription
keywords.main_keyword string ✅ Yes Main keyword for the article
keywords.secondary_keywords array No Array of secondary keywords
website_domain string ✅ Yes Your domain (e.g. marketplacestudio.nl)
article_length_words number No 50-1500 words (default: 800)
enable_no_ai_slop boolean No Remove AI patterns (recommended: true)
enable_seo_optimization boolean No SEO optimization (recommended: true)
enable_first_hand_experience boolean No Add personal experience
first_hand_experience string No Your experience text
⚠️ Common Mistakes:
❌ "main_keyword": "..." (at root level)
✅ "keywords": { "main_keyword": "..." } (correct!)

❌ "article_length_words": 2000 (too long!)
✅ "article_length_words": 1500 (max allowed)

📊 What You Get

SEO Content Title, meta, H1, sections, FAQs
JSON-LD Schemas Article + FAQ structured data
No AI Slop Removes 20+ AI patterns
SEO Insights Related keywords & questions
