Content Creator API Setup

Generate SEO-optimized articles with AI • Add statistics, human experiences & multiple keywords

What You Get

SEO Content Title, meta, H1, sections, FAQs, schemas
Human Experiences Add real testing data & statistics
JSON-LD Schemas Article & FAQ structured data
No AI Slop Removes 20+ AI writing patterns

API Endpoint

POST https://wanda-central.vercel.app/api/content/generate

Rate Limit: 200 requests/day • Timeout: 90 seconds

Basic Request

fetch('https://wanda-central.vercel.app/api/content/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    website_domain: 'yourblog.com',
    main_keyword: 'best coffee makers 2026',
    enable_no_ai_slop: true
  })
})

Add Statistics & Numbers

Include real testing data and measurements:

enable_first_hand_experience: true,
first_hand_experience: `
  Tested 8 coffee makers for 90 days:
  - Breville: 6 minutes brew time
  - Cost: $67 average per machine
  - 45 cups before cleaning needed
  - Temperature: 195°F optimal
`

Target Multiple Keywords

main_keyword: 'best coffee makers',
secondary_keywords: [
  'drip coffee maker',
  'espresso machine',
  'automatic coffee'
]

Enable SEO Optimization

enable_no_ai_slop: true,           // Remove AI patterns
enable_enhanced_humanizer: true,   // Google AI Overviews
enable_seo_optimization: true,     // LSI terms + PAA
include_seo_insights: true         // Related keywords

MCP Server Integration

Connect to Wanda Central via Model Context Protocol for AI agents like Claude:

{
  "mcpServers": {
    "wanda-central": {
      "command": "node",
      "args": ["path/to/wanda-mcp-server"],
      "env": {
        "WANDA_API_URL": "https://wanda-central.vercel.app"
      }
    }
  }
}
