REQUIREMENTS:

2. When clicked, show a form with:
   - Main keyword (required)

   - Enable SEO optimization (checkbox, default true)

3. On submit, call the API:

fetch('https://wanda-central.vercel.app/api/content/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    keywords: {
      main_keyword: 'your keyword here',
      secondary_keywords: ['keyword 2', 'keyword 3']
    },
    website_domain: 'yourblog.com',
    enable_no_ai_slop: true,
    enable_seo_optimization: true,
    article_length_words: 800,
    enable_images: true,  // Request image placeholders
    images_per_article: 3 // Number of images to include
  })
})

4. Parse the response and create a draft post with:
   - Title (from response.content.title)
   - Meta description (from response.content.meta_description)
   - H1 heading (from response.content.h1)
   - Body sections (from response.content.sections array)
   - FAQs (from response.content.faqs array)
   - Images (from response.content.images array with placeholders)
   - JSON-LD schemas (response.content.json_ld_article and json_ld_faq)

🖼️ IMAGE SUPPORT (NEW!)

✅ Image Placeholders Included!
API now returns image placeholders with ChatGPT prompts for generating visuals.

How It Works:

  1. Set enable_images: true in request
  2. API returns 3-5 image placeholders per article
  3. Each includes: position, alt text, caption, and ChatGPT image prompt
  4. Placeholders inserted in strategic positions
  5. Use ChatGPT prompts to generate actual images later

Example Image Response:

  "images": [

    method: 'POST',

      enable_images: true,

}
